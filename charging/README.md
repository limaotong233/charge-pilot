
# 闪充（鸿蒙智能充电） | HarmonyOS / ArkTS / MapKit / ScanKit / TTS

- **独立开发鸿蒙原生跨设备充电服务平台**，基于 **ArkTS 声明式 UI** 构建，通过 **6 大 API 模块 + 6 个 Service 服务**实现业务层解耦

- 集成 **华为 MapKit 地图引擎**，实现充电站热力分布、站点详情弹窗、路线规划导航，支持 **跨设备续接（distributedDataObject）** 保持首页导航状态无缝迁移

- 基于 **状态装饰器（@State/@Link/@Prop/@StorageProp）** 构建多端响应式布局，通过 **currentBreakpoint** 动态适配 Phone/Tablet/2in1，手机端底部 Tab 导航与平板端左侧导航栏智能切换

- 实现 **扫码即充** 流程：集成 **ScanKit** 解析充电桩二维码 → 自动创建订单 → 实时充电进度环形展示（电量/金额/时长） → 支付结算，闭环体验

- 集成 **TTS 语音合成引擎**，充电过程中按可配间隔（15s/30s/60s）播报进度，通过 **长时任务（audioPlayback + location）** 实现息屏后台持续播报，电量满时推送 **系统通知**

- 支持 **有序桩绑定 + 预约充电**：模糊搜索充电站/充电桩 → 预约时段（DatePickerDialog）→ SOC 目标值设置（Slider 20%~100%，步长 5%）→ 定时轮询状态 → **桌面服务卡片**实时展示

- 支持 **批量收藏**站点管理、分页懒加载订单列表（全部/待支付/已完成三 Tab）、**代金券卡券系统**（领取/抵扣，最多 10 张限制）、5 步图文使用教程

- 覆盖 **位置权限、相机扫码、麦克风语音、后台运行**等多权限管理，统一的 **Http 请求封装**自动处理 Token 认证与失效跳转
